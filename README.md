## Назначение программы
Проект состоит из двух модулей:
1. **`KhlusMathLib.dll`** — динамически подключаемая библиотека, экспортирующая функции обработки массивов чисел типа `double` (`ArraySum`, `ArrayMin`, `ArrayMax`, `ArrayAverage`) через C-совместимый интерфейс (`extern "C"`, `__cdecl`).
2. **`lab06_app.exe`** — консольное приложение Windows, выполняющее явную загрузку библиотеки во время выполнения, проверку корректности вычислений, демонстрацию обработки системных ошибок, бенчмаркинг на массивах из 100, 1000 и 10000 элементов и контролируемую выгрузку библиотеки.

## Используемые Windows API
- `LoadLibraryA()` — явная загрузка DLL в адресное пространство процесса;
- `GetProcAddress()` — получение адресов экспортируемых функций по имени;
- `FreeLibrary()` — выгрузка DLL и освобождение ресурсов;
- `GetModuleFileNameA()` / `GetModuleHandleA()` — получение полного пути модуля и проверка его выгрузки;
- `QueryPerformanceCounter()` / `QueryPerformanceFrequency()` — высокоточные измерения времени;
- `GetLastError()` / `FormatMessageA()` — получение кода и текстового описания системных ошибок;
- `GetLocalTime()` — формирование временных меток журнала.

## Порядок сборки (CLion / CMake)
1. Открыть каталог `lab06-system` в **CLion** как CMake-проект.
2. Выбрать профиль сборки (`Debug` или `Release`, рекомендуется `Release` для замеров производительности).
3. Собрать цель `lab06_app` (библиотека `KhlusMathLib.dll` соберётся автоматически и окажется в той же папке `bin/`).

Либо через консоль:
```bat
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

## Параметры запуска
```bat
lab06_app.exe [--dll <path>] [--mode demo|benchmark|test-errors|all] [--size <N>] [--student-id <id>] [--seed <S>] [--runs <R>] [--iterations <K>] [--export <csv>] [--log <log>]
```

Пример запуска всех этапов (демонстрация + тесты ошибок + эксперименты):
```bat
build\bin\lab06_app.exe --dll build\bin\KhlusMathLib.dll --mode all --student-id 114 --runs 3 --iterations 1000 --export data\benchmark_results.csv --log data\lab06_run.log
```

## Воспроизведение экспериментов и построение графиков
1. Запустить `tests\run_tests.bat` (или команду выше).
2. Построить графики из полученных CSV-данных:
```bat

```

## Ограничения доступа и безопасности
Приложение работает исключительно в пользовательском режиме (User Mode) без прав администратора, не изменяет системный реестр Windows и не внедряет DLL в сторонние процессы.
